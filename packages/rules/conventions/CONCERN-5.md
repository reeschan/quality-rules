# 公開する口は公開ファイルだけにする

## 理由

モジュールの外から中のファイルを直接読めると、中の作りを変えるたびに、読んでいる外の全部を直すことになる。外から使ってよい口を公開ファイルだけに決め、中のファイルは外から読ませなければ、中の作りを自由に変えられ、外が何に頼っているかも公開ファイルを見れば分かる。

## 確かめる問い

- 外から使うものは、すべて公開ファイルを通して取り出せるか。
- 公開ファイルに、外から使われない中身まで並べていないか。
- 中のファイルを読ませるために、公開の口をすり抜ける道を作っていないか。

## 機械では拾えない残り

ルールが拾うのは、閉じたモジュールの公開ファイル以外を、外から import している箇所だけ。次はレビューで見る。

- どのまとまりを 1 つのモジュールとして閉じるか、という切り方そのもの。
- 公開ファイルが、外に見せる必要のないものまで再公開していないか。
- import を使わない経路（動的に組み立てたパスなど）で、中のファイルに触れていないか。
